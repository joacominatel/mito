# Mito

A native macOS companion for League of Legends: auto-accept, champ select recommendations,
and runes, spells, and item sets imported automatically for each matchup.

- `apps/macos/` — the SwiftUI app and its local packages.
- `MITO_CONTEXT.md` — the project's source of truth (Spanish).

Open `apps/macos/Mito.xcodeproj` in Xcode, or run the package tests with
`swift test --package-path apps/macos/Packages/<Name>`.
